WristBilibili API 接口清单（2026 最新更新版）

来源（原）：WristBilibili-master/app/src/main/java/cn/luern0313/wristbilibili/api/
来源（新）：GitHub 开源库 BiliBili-API-main（com.esdllm.bilibiliApi，Java 客户端，2026-09 持续实测维护）
更新方式：逐条对照 2026-09-23 实际请求实测（curl，UA=Chrome/124 Windows，Referer=https://www.bilibili.com/）+
          镜像文档（lxb007981.github.io/bilibili-API-collect、gitee.com/MrVanme/bilibili-API-collect）+
          本 GitHub 新库的实测结论（含 WBI 签名 2×2 对照表、playurl 路径对照等）

说明：
- 每条接口标注【状态】：沿用 / 替换 / 废弃 / 未确认
- 【鉴权】列说明 2026 年调用所需的凭据：Cookie / CSRF（bili_jct）/ WBI 签名 / buvid3 设备指纹
- 原始清单中的"源码旧接口"保留在【旧 URL】里供对照；2026 年可直接使用的写在【URL】
- 实测规则：GET 返回 JSON code=0 为可用；POST 不带 Cookie 返回 -101/-401/-352（非 404）即端点存活；
  -412 = 需 WBI；-352 = 风控（多为缺 buvid3 或 UA/Referer 形状不对）
- 所有 POST 接口仅验证端点存活，未发起任何真实点赞/投币/收藏等破坏性请求

==========================================================================================
2026 年新增鉴权要点（最容易踩坑，总结）
==========================================================================================

1. WBI 签名（w_rid + wts）已强制覆盖：
   - x/space/wbi/acc/info（用户信息）—— 签名+凭据两者都要
   - x/space/wbi/arc/search（用户投稿）—— 签名+凭据两者都要
   - x/relation/followers（粉丝列表）—— 签名+凭据
   - x/polymer/web-dynamic/v1/feed/space（空间动态）—— 签名
   - x/v3/fav/resource/deal（收藏操作）—— 签名
   - 注意不对称：x/relation/followings 未强制 WBI；wbi/search/all/v2 与 wbi/search/type
     实测不强制签名（文档标注过时）
   - 密钥来源：GET /x/web-interface/nav → data.wbi_img.img_url/sub_url 文件名 → 混淆表取32位
     签名实现：wts=时间戳 + 参数按 key 排序 + md5(query+mixinKey) → w_rid

2. buvid3 设备指纹（Cookie）：
   - 涉及端点：x/web-interface/popular/series/one 等（裸调 -352）
   - 获取：GET https://api.bilibili.com/x/frontend/finger/spi → data.b_3 → 写入 Cookie buvid3

3. 风控 -352 常见原因：缺 buvid3 / UA 或 Referer 形状不对（如 ranking 用站根 Referer）/
   请求头 Accept 用文档型而非 application/json, text/plain, */*

4. 域名迁移总览：
   - 动态读取：api.vc.bilibili.com/dynamic_svr/* → api.bilibili.com/x/polymer/web-dynamic/v1/*
     （写入仍留 vc 域）
   - 收藏体系：space.bilibili.com/ajax/fav/* + medialist/gateway/coll/* + x/space/fav/arc
     → x/v3/fav/*（folder/created/list-all、folder/info、resource/list、resource/deal）
   - 番剧详情：pgc/view/app/season → pgc/view/web/season
   - 视频信息：app.bilibili.com/x/v2/view → x/web-interface/view
   - 用户空间：app.bilibili.com/x/v2/space → x/space/wbi/acc/info
   - 登录：passport qrcode 旧双端 → x/passport-login/web/qrcode/generate+poll；
     TV 密码登录 v3/oauth2 通道关闭无替代；login/app/third 关闭

1. 设备（手表/手机）运行 frida-server（需 root 或模拟器）：
   adb push frida-server-<ver>-android-arm64 /data/local/tmp/frida-server
   adb shell "chmod 755 /data/local/tmp/frida-server && /data/local/tmp/frida-server &"
2. PC 端安装：pip install frida frida-tools frida-dexdump objection
3. 一键脱壳：frida-dexdump -U -f cn.luern0313.wristbilibili
4. 深度抓取：frida -U -f cn.luern0313.wristbilibili -l dump_dex.js --no-pause
   （hook art::DexFile::OpenMemory / dvmJarFileOpen_stub / find_dexfile，把内存中 DEX 写盘）
5. 直接抓真实请求：hook java.net.URL / okhttp3.RealCall.execute，打印 url 与参数
6. jadx 反编译 dump 出的 dex，全局搜索 api.bilibili.com / passport.bilibili.com 即可拿到
   4.6 加密壳内的精确接口全集。
